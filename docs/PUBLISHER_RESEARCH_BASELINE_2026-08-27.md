# 出版社公開教材研究基線

更新日期：2026-08-27
用途：為五科逐單元「完整自行撰寫教學本文」建立可追溯的出版社研究入口。這不是教材複製庫，也不把出版社的章節名稱當作本專案的 Knowledge Graph ID。

## 可採用與不可採用的界線

1. 課程事實仍以國家教育研究院的官方課綱為準；出版社資料用來交叉核對學習序列、常見表徵、活動型態與版面所服務的教學目的。
2. 每個重寫單元至少要有一筆 `publisherResearch`，其中必須列出出版者、版本／冊次、可定位的章節或單元、公開 URL、查核日、實際閱覽範圍及「自行轉化」說明。
3. 不存取或轉錄出版社課文、插圖、投影片、習題、解答、音檔／影片逐字稿及教師用書。頁面若要求登入、教師驗證、下載或標示僅供校內教學，即記為不可採集，不繞過限制。
4. 研究後的教材必須先有完整教學正文（情境、概念建構、原創例題、引導練習、遷移與自我檢核），最後才有摘要重點；所有例題、題目、情境與解答皆另行自編。

## 已確認的權利限制

- 康軒影音頁明示內容受著作權保護，供教師在法定範圍內教學使用；本專案只登錄 URL、章節定位與研究結論。
- 南一 OneBox／教師資源頁明示電子書與題庫須教師身分登入，且教材僅供教學使用；它們不列為可採集內容來源。
- 翰林公開的教用檔案與教材入口雖可由公開 URL 取得，仍屬受著作權保護的教材；不匯入、鏡像、逐字摘錄或重製。

## 2026-08-27 重寫覆蓋快照

五科官方課綱的 583 個 `learning-content` 單元，加上 4 個補充原創單元，及其餘 444 個可用的分類／能力頁，合計 1,031 個 lesson 均已建立 `full-lesson-v1`。每筆均包含六階段自編正文、四點摘要、三項離堂檢核與對應出版社公開研究紀錄；數學 126 頁、自然 325 頁另提供學科互動。`lessonScope` 保留 `theme`、`topic`、`learning-performance` 等層級，避免把導覽／能力頁誤稱為出版社章節或教材單元。

## 已完成的數學 A-7 試點

1. 以官方課綱 `A-7-1`～`A-7-5` 作為必教事實與範圍。
2. 以翰林 1A／1B 公開影音頁所見的教學序列，檢查正文是否依序完成概念建構、分步解題、回顧、自評與挑戰；這只是結構參考，非內容來源轉錄。
3. 以自編情境、不同數值、原創互動操作與自編診斷題完成正文；摘要固定在正文後呈現。
4. 五個 lesson 均記錄 `publisherResearch` 的 URL、定位、研究範圍與不複製聲明，並通過新 validator 與前端互動實測。
