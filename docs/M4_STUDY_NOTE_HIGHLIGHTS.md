# M4 學霸筆記重點整合紀錄

## 使用方式

本次先搜尋公開可讀的學習筆記／複習策略頁面，擷取「學習策略與觀念檢核」層級的重點，再以本專案自己的語言改寫成每個 lesson 的 `studyHighlights`。這些文字不是外部筆記的逐句轉載，也沒有匯入外部題目、選項或答案。

## 外部參考

- [Stoody：國中會考自然科怎麼讀？](https://www.stoody.com.tw/blog-detail/149)：理解再記憶、圖表／實驗題、錯題標記與重做、康乃爾筆記／心智圖。
- [均一教育平台：比熱](https://www.junyiacademy.org/videos/mfEfvb9SX20?topic=junyi-science%2Fscience-juni%2Fmiddle-school-physics-chemistry/s4zwd-)：比熱單元的概念複習入口。
- [Clearnote 國中數學公開筆記索引](https://www.clearnotebooks.com/zh-TW/notebooks/grade/junior-high?q=%E6%95%B8%E5%AD%B8)：觀察公開筆記的常見整理主題與索引方式。
- [王立第二戰研所：因式分解與一元二次方程式](https://vocus.cc/article/621269b6fd89780001676097)：以動手計算、整除概念與驗算取代只靠外觀猜測。

## 內容落點

- 10 份 lesson 均加入至少 3 條 `studyHighlights` 與可追溯的 `studyReferences`。
- 數學／自然 4 份 lesson 另外加入至少 3 步 `interactive.guided-choice`，前端可即時選答案並顯示回饋。
- 外部頁面只作為重點研究與事實查核；本 repo 的 lesson、100 題 question、答案與解析仍標記 `origin=original`。
- 未來若要納入受授權的外部題目，必須改用 `official-open` 或 `licensed` provenance，記錄授權與 source locator，不得標成 original。
