# M4／M3 出版社來源狀態

## 南一

- 範圍：30 冊。
- 已有：國教院冊別清冊、校方課程計畫、教育平台等交叉證據。
- 缺少：出版社正式逐冊章節目次、固定公開 URL／頁碼、逐碼 KG 對照。
- 狀態：`blocked`（出版社 alignment）；不阻擋官方課綱內容建立。

## 翰林非國文

- 範圍：英文、數學、自然、社會共 24 冊。
- 已有：數學官方影音索引、社會教材目次 metadata、部分英文／自然官方或校方資料。
- 缺少：完整出版社正式逐冊目次與逐碼 KG 對照，尤其版本／學年度一致性。
- 狀態：`blocked`（出版社 alignment）；不阻擋官方課綱內容建立。

校方課程計畫、商品存在頁、搜尋摘要與登入後資源只能作交叉證據；不能宣稱出版社背書，也不能複製受著作權保護的教材內容。
